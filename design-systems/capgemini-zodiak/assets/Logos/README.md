# Logos

The Capgemini 2025 logo set, copied from the brand package. Four marks, each as SVG for screen and PNG for places that cannot take vector.

| File | Ink | Use on |
| --- | --- | --- |
| `capgemini-logo-blue.svg` / `.png` | #0058AB (`brand-capgemini-blue`) | `page-background`, `surface-always-white`, light photography |
| `capgemini-logo-white.svg` / `.png` | #FFFFFF (`brand-white`) | `surface-ink-heavy`, `surface-marine-heavy`, `surface-azur-heavy`, dark photography |
| `capgemini-spade-blue.svg` / `.png` | #0058AB (`brand-capgemini-blue`) | favicons, app icons, avatars on light grounds |
| `capgemini-spade-white.svg` / `.png` | #FFFFFF (`brand-white`) | favicons, app icons, avatars on dark grounds |

The ink is baked into each file. These SVGs do not use `currentColor`, so an `<img>` cannot recolour them — pick the file that matches the ground.

Aspect ratios: the lockup is 358 × 117, the spade 150 × 139. Scale proportionally; never stretch, rotate or crop.

Clear space is the spade's height on all four sides. Minimum width 120px for the lockup, 32px for the spade.

Print files (CMYK Illustrator artwork, the Pantone-matched sets) are in the brand package and are not carried here.
